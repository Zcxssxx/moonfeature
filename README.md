# MoonFeature

MoonFeature is an OpenFeature-inspired server-side feature flag SDK for MoonBit. It aims to provide typed evaluation, explicit evaluation contexts, pluggable providers, and a deterministic in-memory rules provider.

**Project status:** early development. The API, supported targets, and conformance profile are not yet finalized. This project does not claim full OpenFeature conformance.

See [the design](docs/superpowers/specs/2026-10-24-openfeature-sdk-design.md) and [source/provenance notes](docs/sources.md).
