# Source and provenance

The initial MoonBit implementation, tests, examples, and synthetic feature-flag data are authored for this repository. No upstream SDK implementation or third-party test corpus is copied or vendored.

OpenFeature specification pages are normative behavioral references. They are linked in the design document and will be mapped to implementation and tests in `docs/conformance.md`. The OpenFeature specification itself is not included as source code.

The behavior profile was rechecked on 2026-10-25 against the official [Flag Evaluation API](https://openfeature.dev/specification/sections/flag-evaluation/), [Provider](https://openfeature.dev/specification/sections/providers/), [Evaluation Context](https://openfeature.dev/specification/sections/evaluation-context/), [Hooks](https://openfeature.dev/specification/sections/hooks/), [Events](https://openfeature.dev/specification/sections/events/), and [Types and Data Structures](https://openfeature.dev/specification/types/) pages. MoonBit executable package syntax was checked against the official [package configuration documentation](https://docs.moonbitlang.com/en/latest/toolchain/moon/package.html). These pages are references; implementation and tests are authored for this repository.

The CI workflow was independently adapted on 2026-10-25 after reviewing the supplied [MoonBit CI example](https://github.com/PaiGack/moonbitlang-OSC2026/blob/main/.github/workflows/test.yml) and the [MoonBit community workflow templates](https://github.com/moonbit-community/.github/tree/main/workflow-templates/check.yml). The checkout action is pinned to the signed [v7.0.1 release commit](https://github.com/actions/checkout/releases/tag/v7.0.1); this Node 24 release avoids the Node 20 runtime retirement announced by [GitHub Actions](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions/). No workflow file was copied verbatim.

Runtime dependencies are MoonBit core packages only: `moonbitlang/core/ref` for isolated mutable API/provider state and `moonbitlang/core/encoding/utf8` for stable cross-target rollout hashing. No external Mooncakes package, vendored implementation, or third-party fixture is used. Reassess this record whenever a dependency or external fixture is added; record its exact upstream URL, version, license, and the files that use it.
